## Getting Started

These instructions will get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- Node.js (recommended LTS)
- npm or Yarn

### Install

1. Clone the repo

```bash
git clone https://github.com/aladilashrafi/adil-portfolio.git
cd adil-portfolio
```

2. Install dependencies (adjust for npm or Yarn)

```bash
npm install
# or
# yarn install
```

### Run Locally

If this project uses a typical JS framework (React/Next/Vue):

```bash
npm run dev
# or
# yarn dev
```

Open http://localhost:3000 (or the port your project uses) to view the site.

If the site is a static HTML/CSS project, open `index.html` in your browser or serve it with a static server.
